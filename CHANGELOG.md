# Changelog

Todos los cambios notables de este proyecto se documentan en este archivo.

El formato sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/)
y el proyecto usa [Versionado Semántico](https://semver.org/lang/es/)
(`MAJOR.MINOR.PATCH`). A partir de esta versión, las entradas nuevas se
generan automáticamente vía [release-please](https://github.com/googleapis/release-please)
a partir de los mensajes de commit (Conventional Commits) — ver
[wiki/Versionado.md](wiki/Versionado.md).

## [1.0.0] - 2026-08-11

Primera versión estable de Logify: plataforma SaaS de gestión logística y
comercial multi-tenant (pedidos B2B, inventario, envíos, notificaciones y
POS B2C) con arquitectura de microservicios, RBAC de 7 roles, PWA,
monitoreo y despliegue en VPS + Vercel.
